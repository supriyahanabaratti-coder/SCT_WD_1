# Task 01 - Responsive Landing Page

## Project Overview

This project is a responsive landing page created as part of Task 01.

The main objective of this task is to create an interactive navigation menu that changes its style when the user hovers over a menu item or scrolls the page.

The navigation menu has a fixed position, so it remains visible while the user scrolls through different sections of the page.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- VS Code
- Google Chrome
- Git & GitHub

---

## Features

### 1. Fixed Navigation Bar

The navigation bar stays at the top of the screen while scrolling.

### 2. Hover Effect

When the user moves the mouse over a navigation item:

- The text color changes.
- An animated underline appears.

### 3. Scroll Effect

When the user scrolls down:

- The navigation background changes.
- The navigation bar gets a shadow.
- The logo and menu colors change.

### 4. Smooth Scrolling

Clicking a navigation item smoothly moves the user to the selected section.

### 5. Responsive Design

The website works on:

- 💻 Desktop
- 📱 Mobile
- 📲 Tablet

### 6. Mobile Navigation

On smaller screens, a hamburger menu is displayed.
